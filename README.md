# 📝 Живой Блокнот с синхронизацией в реальном времени

Стильное, адаптивное веб-приложение для заметок и задач на чистом HTML, CSS и JavaScript с мгновенной облачной синхронизацией через **Google Firebase Firestore**.

---

## ⚡ Как подключить Firebase за 4 простых шага (на пальцах)

Вам понадобится любой Google-аккаунт. Это на 100% бесплатно и не требует банковских карт.

### Шаг 1. Создайте проект
1. Перейдите на сайт [console.firebase.google.com](https://console.firebase.google.com/) и войдите под своим Google-аккаунтом.
2. Нажмите синюю кнопку **«Создать проект»** (или «Добавить проект»).
3. Введите любое название (например, `live-notes`) и нажмите **«Продолжить»**.
4. На шаге Google Аналитики можно снять галочку или оставить как есть &rarr; нажмите **«Создать проект»** и подождите 15 секунд.

### Шаг 2. Включите базу данных Firestore
1. В меню слева нажмите **«Сборка»** (Build) &rarr; **«База данных Firestore»** (Firestore Database).
2. Нажмите кнопку **«Создать базу данных»**.
3. **ВАЖНО:** Когда спросят про правила доступа, выберите **«Начать в тестовом режиме»** (Start in test mode) &rarr; нажмите «Далее» &rarr; выберите ближайший регион (например, `europe-west`) и нажмите **«Включить»**.
> *Примечание:* Тестовый режим сразу разрешает приложению свободно читать и записывать заметки без авторизации.

### Шаг 3. Зарегистрируйте веб-приложение и скопируйте ключи
1. В меню слева нажмите на значок шестеренки ⚙️ (вверху рядом с «Обзор проекта») &rarr; **«Настройки проекта»**.
2. Прокрутите страницу вниз до раздела «Ваши приложения» и нажмите на круглую иконку веба **`</>`**.
3. Введите название приложения (например, `Notepad Web`) и нажмите **«Зарегистрировать приложение»**.
4. Прокрутите чуть ниже и найдите блок `const firebaseConfig = { ... }`.
   Скопируйте эти 6 строк с вашими ключами:
   ```javascript
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "live-notes-xyz.firebaseapp.com",
     projectId: "live-notes-xyz",
     storageBucket: "live-notes-xyz.appspot.com",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef"
   };
   ```

### Шаг 4. Вставьте ключи в код
1. Откройте файл `app.js` в блокноте или редакторе кода.
2. В самом верху замените шаблонный блок `firebaseConfig` на свои скопированные ключи.
3. Сохраните файл!

## 🚀 Как проверить синхронизацию на телефоне и ПК

1. **На компьютере:** Дважды кликните по файлу `index.html` — он откроется в браузере. Индикатор сверху загорится зеленым («В сети • Онлайн»).
2. **Как открыть на телефоне:**
   - **Самый быстрый способ (бесплатный хостинг):**
     Загрузите папку с файлами на [GitHub Pages](https://pages.github.com/) или перетащите мышкой в [Vercel](https://vercel.com/) / [Netlify Drop](https://app.netlify.com/drop). Вы получите готовую ссылку (например, `https://my-notes.vercel.app`), которую можно открыть на телефоне.
   - **Или локально через одну Wi-Fi сеть:** запустите локальный сервер (например, в VS Code расширение Live Server или команду `python -m http.server 8080`) и откройте IP вашего компьютера на телефоне.
3. Добавьте заметку на телефоне — она **мгновенно появится на мониторе ПК без перезагрузки страницы!**
